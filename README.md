# 🏛️ 보강 경매 시스템 (Substitution Auction Web App)

구글 스프레드시트와 연동되어 사전에 계획된 보강이 필요한 수업을 등록하고, 교사들이 자유롭게 보강을 신청(경매 체결)할 수 있는 **Google Apps Script 웹 애플리케이션**입니다.

기존 **[`홍익-보강 알리미`](https://github.com/xoruddkqk4-glitch/makeup_class_auction)** 시스템과의 표준 연동 규격(`결강 교사(원교사)`, `보강 교사`, `보강 교과`, `보강 유발 사유`, `날짜(요일)`) 및 라이트 테마 디자인, 폼 구성(교시 칩 선택, 층별/교실 2단계 셀렉터, 교과/사유 추천 태그), **테이블 레이아웃(1100px 너비)** 및 **상세 필터/정렬 툴바**를 완벽하게 통일하였습니다.

## 🚀 주요 기능 및 디자인 표준

### 1. `홍익-보강 알리미` 표준 통일 테이블 뷰 & 검색/필터
- **테이블 가로 너비 & 10개 컬럼 레이아웃**: `1100px` 너비 표준 적용.
  - 컬럼 구성: `날짜(요일)`, `교시`, `교실`, `보강 교과`, `결강 교사(원교사)`, `보강 사유`, `마감 시간 / 상태`, `보강 신청`, `수업계 확인`, `작업`
- **단일 행 레이아웃 (`white-space: nowrap`) & 선명한 헤더**:
  - 모든 셀 데이터가 줄바꿈 없이 1줄로 표시되도록 레이아웃 및 폰트 크기 최적화.
  - 헤더 텍스트 및 정렬 아이콘 색상을 선명한 흰색(`#ffffff !important`)으로 스타일 통일.
- **메인 타이틀 & 조회 기간 동적 배지**:
  - 타이틀: `보강 경매 시스템`
  - 기간 검색 시 메인 타이틀 우측에 조회된 날짜 범위 배지(`YYYY-MM-DD ~ YYYY-MM-DD`) 자동 표시.
  - 모든 날짜 검색 및 프리셋 기준은 사용자 컴퓨터 시간(로컬 시스템 시각)을 기준으로 동작.
- **통합 툴바 (Table Header)**:
  - **날짜 기간 선택기**: 지정한 날짜 범위(`filterStartDate` ~ `filterEndDate`) 내 경매 항목 조회.
  - **날짜 프리셋 버튼 그룹**: `지난달`, `지난주`, `오늘`, `이번주`, `다음주`, `이번달`, `전체 보기` 1-클릭 프리셋.
  - **동적 미세 애니메이션 & 토스트 알림**: `새로고침`(회전 애니메이션), `초기화`(역회전 애니메이션) 버튼 클릭 시 클릭 인터랙션 및 토스트 메시지 제공.
  - **상단 우측 액션 버튼**: `+ 보강 경매 등록하기` 버튼을 위치시켜 클릭 시 모달 팝업으로 등록 폼 실행.
- **개별 컬럼 필터 행 (Column Filters)**:
  - 상태(신청 가능/마감), 교시(1~7교시), 교실(층/호수별), 보강 교과, 원교사 검색, 보강 사유 필터 및 `필터 초기화` 버튼 제공.
- **테이블 헤더 정렬 (Sorting)**:
  - 날짜, 교시, 교실, 교과, 원교사, 사유, 마감 상태 등 헤더 클릭 시 오름차순/내림차순 정렬.

### 2. 사전 계획 보강 내역 등록 및 수정 (모달 팝업 폼)
- **신규 보강 경매 등록 (`+ 보강 경매 등록하기`)**:
  - Step 1. 날짜 지정: 보강 필요 날짜 지정 (오늘 이후)
  - Step 2. 교시 선택: 1~7교시 직관적 인터랙티브 칩 컴포넌트 (`1교시`~`7교시`)
  - Step 3. 교실 선택: 층별(`4층`, `3층`, `2층`, `1층`, `지하(B층)`) 및 호수(`401~416`, `301~316`, `201~216`, `101~115`, `B01~B14`) 2단계 동적 셀렉터
  - Step 4. 보강 교과: 직접 입력 + 추천 교과 태그 칩 (`#국어`, `#수학`, `#영어`, `#사회`, `#과학`, `#체육`, `#음악`, `#미술`, `#정보` 등 커스텀 추가/삭제 및 `localStorage` 자동 공유)
  - Step 5. 결강 교사(원교사): 결강 교사 성명 입력 (`보강 알리미` 용어 통일)
  - Step 6. 보강 유발 사유: 직접 입력 + 추천 사유 태그 칩 (`#출장`, `#연가`, `#병가`, `#공가`, `#특별휴가`, `#조퇴`, `#외출` 등 커스텀 추가/삭제 및 `localStorage` 자동 공유)
- **기존 보강 경매 수정 (`✏️ 수정 버튼`)**:
  - `작업` 컬럼 내 수정 버튼 제공.
  - 마감 기한이 지난 경매 항목도 수정 가능.
  - 수정 클릭 시 `#editAuctionModal`이 호출되어 날짜, 교시, 교실, 교과, 원교사, 사유 항목 갱신 기능 제공 (`updateAuctionRecord` 백엔드 함수 연동).

### 3. 보강 경매 신청 & 업무 담당자 '수업계 확인' 토글 검토 및 보강 알리미 이관
- **Step 1. 보강 신청 접수**:
  - 보강을 원하는 교사는 테이블 목록의 해당 행에서 본인의 성함(`보강 교사 성명`)을 입력하고 **[🙋‍♂️ 신청]** 버튼을 누릅니다.
  - 신청 즉시 `보강경매` 시트에 보강 교사 성명이 저장되고 상태가 `⏳ 승인대기`로 전환되며, **신청 교사 성명 입력창이 비활성화(`disabled`)** 처리됩니다. (필요 시 `[신청취소]` 버튼으로 취소 가능)
- **Step 2. 업무 담당자 '수업계 확인' 토글 승인 (True)**:
  - 각 행의 **'수업계 확인' 토글 스위치**를 업무 담당자(수업계)가 클릭하여 **True (ON)** 상태로 설정합니다.
  - 토글 승인 시:
    1. 해당 건이 **`보강내역` 시트 (보강 알리미 DB)**로 자동 이관되며, **`확인여부` 값이 기본 `true` (✅ 본인 확인 완료)**로 설정되어 `보강 알리미`에 즉시 반영됩니다.
    2. 이관이 완료된 건은 **`보강경매` 목록에서 자동으로 삭제** 처리됩니다.

### 4. ⚡ 구글 시트 속도 최적화 (CacheService & 0ms 사전 렌더링)
- **Apps Script `CacheService` 서버 캐싱**: `getAuctionRecords()` 호출 시 구글 시트 데이터 결과를 30초 동안 30ms 초고속 캐시 응답.
- **브라우저 `localStorage` 사전 렌더링**: 접속 시 이전 데이터를 0ms 체감 속도로 즉시 표시 후 백그라운드 서버 동기화.
- **캐시 자동 갱신**: 신규 등록/수정/삭제/신청/승인 시 `clearAuctionCache()`가 자동 실행되어 최신 데이터 동기화.

### 5. 마감 처리 및 자동 정리 조건
- **등록 마감 제약**: 
  - **당일 5교시 ~ 7교시** 보강 등록 시 ➡️ `마감 시간이 초과되어 등록할 수 없습니다.` 메시지 출력 및 차단.
  - **다음날(익일) 1교시 ~ 4교시** 보강 등록 시 ➡️ `마감 시간이 초과되어 등록할 수 없습니다.` 메시지 출력 및 차단.
- **전날 13시 신청 마감**: 보강 날짜 전날 13:00가 경과하면 신규 신청이 마감되며 버튼이 비활성화됩니다. (마감 건도 수정 아이콘으로 상세 수정 가능)
- **지난 날짜 자동 삭제**: 미신청 상태로 보강 날짜가 지난 항목은 `getAuctionRecords()` 호출 시 또는 주기적 트리거를 통해 `보강경매` 시트에서 자동 삭제됩니다.

## 🛠️ script.google.com 배포 안내 (Deployment Guide)

1. **[script.google.com](https://script.google.com) 접속** 및 **새 프로젝트 생성** (프로젝트명: `홍익_보강 경매`).
2. 프로젝트에 2개의 파일 생성:
   - `Code.gs`: 본 저장소의 [`Code.gs`](file:///c:/Users/user/Desktop/appsscript/%ED%99%8D%EC%9D%B5_%EB%B3%B4%EA%B0%95%20%EA%B2%BD%EB%A7%A4/Code.gs) 내용 전체 복사/붙여넣기
   - `index.html`: 본 저장소의 [`index.html`](file:///c:/Users/user/Desktop/appsscript/%ED%99%8D%EC%9D%B5_%EB%B3%B4%EA%B0%95%20%EA%B2%BD%EB%A7%A4/index.html) 내용 전체 복사/붙여넣기
3. **웹앱 배포**:
   - 우측 상단 **[배포]** ➡️ **[새 배포]** 클릭
   - 유형 선택: **웹 앱 (Web App)**
   - 실행 대상: **나 (Me)**
   - 액세스 권한: **모든 사용자 (Anyone)** 또는 **조직 내부 사용자**
   - **[배포]** 클릭 후 부여받은 웹앱 URL을 교직원에게 공유합니다.
4. *(옵션)* **자동 정리 트리거 설정**:
   - Apps Script 좌측 메뉴 ➡️ **[트리거 (시계 아이콘)]** 클릭
   - `autoCleanupAuctions` 함수를 **시간 기반 트리거 (매일 13시 또는 매시간)**로 등록하면 지난 경매가 자동으로 정기 삭제됩니다.
